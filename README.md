# About

This python script simulates the effect that congestion control has on a network. To run it, simply navigate a Command Prompt (Windows) or Terminal (Unix) to this folder, and then type the following commands in order:

Install the required libraries:
`pip install -r requirements.txt`

Run the program:
`python ./network_attack_with_CC.py`

You will then be prompted to type a number to run the simuation with a specific type of congestion control.
